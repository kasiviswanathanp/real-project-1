# Anbu Physiotherapy Clinic — Frontend

Frontend-only demo website for Anbu Physiotherapy Clinic.

## Run locally
Open `index.html` directly in Chrome, or use VS Code Live Server.

## Deploy
Upload the project to GitHub and import the repository into Vercel.

## Before publishing
Replace temporary/missing information such as:
- Clinic phone number
- WhatsApp number
- Actual clinic timings
- Real photos
- Verified list of services
- Any other clinic-specific information

The appointment form is currently frontend-only and does not store or transmit patient data.
